# 验证范围

## v0.1.2 优化预览版（2026-09-11）

- `zsh build.sh`：通过原生编译及 ad-hoc 签名完整性验证。下列 GUI 与开关检查来自同一份 Swift 源码的本地构建；发布构建另更新了版本号与文档，未重新进行 GUI 授权和动画验收。
- `zsh -n build.sh package.sh`、`plutil -lint Info.plist`、`git diff --check`：通过。
- v0.1.2 发布包：`zsh package.sh`、DMG/ZIP 的 SHA-256 校验、`hdiutil verify` 及只读挂载后的应用签名检查通过；包内版本为 0.1.2 / build 3，包含安装说明与 MIT 许可证。
- 优化构建已部署到本地应用，控制窗口展示新的 Esc 提示，观察到真实传感器读数 106°。
- 原有应用在更新前可以进入保持预览并用 Esc 返回就绪；此结果不代表新构建通过渲染验收。新构建因 ad-hoc 身份变化显示需要录屏权限，预览按钮正确禁用。
- 用户随后完成首轮优化构建授权，反馈“第一次会晃动一下，后边就好了”。据此追加首帧完成后显示覆盖层、等待首帧再推进动画及单帧在途限制；最终构建再次编译通过并部署，但仍需更新授权后复验，不能声明首次抖动已消除。
- 最终构建已通过界面验证：关闭自动效果，退出并重新启动后开关仍为关闭；随后恢复为开启。此检查不依赖录屏权限。
- 使用 `top -l 4 -s 2 -pid <PID> -stats pid,command,cpu,mem,threads,idlew` 短时采样：旧应用非首样本 CPU 为 1.5% / 2.2% / 2.7%，新应用为 3.5% / 3.5% / 5.3%。采样期间整机负载明显变化，且两者权限状态不同，不能据此判断优化收益；当前没有证据宣称 CPU 或耗电下降。
- 60 / 30 / 5 / 1 Hz 是代码中的定时器目标频率，不是实测帧率或系统唤醒次数。GPU 使用率、动画帧时间及电量尚未测量。
- 待实机验收：新构建授权后的播放/保持/恢复、88°–92° 往返、快速和缓慢开合、锁屏唤醒；本版作为未公证预览版发布，这些场景通过后再制作验收演示。

## 已发布 v0.1.1

本版仅将模糊半径从 64 提高到 96。下方控制窗口与开关检查为此前交互版本的验证记录；增强后的实际虚化效果尚未复验，不能据此声明视觉验收通过。

## 发布前已验证

- Swift 类型检查、原生应用完整构建、Info.plist 格式和 ad-hoc 签名完整性。
- 应用图标与实际控制窗口布局；权限不足时禁用预览并给出入口。
- 自动效果开关关闭与重新开启。
- DMG / ZIP 的 SHA-256 校验、DMG 镜像校验、只读挂载后的应用签名、安装说明与许可证文件。
- 在 MacBook Pro M1 Pro（MacBookPro18,3）观察到实际角度读数。

## 仍待验证

- 最终发布构建在录屏授权生效后的保持/结束预览、Esc 恢复。
- 最终发布构建的真实开合盖、88°–92° 临界区与唤醒/锁屏回归。
- 其他 MacBook 型号、不同缩放设置、多显示器及完整安装/升级流程。
- Developer ID 签名与 Apple 公证。当前维护环境没有可用签名身份，也尚未加入 Apple Developer Program。

GitHub Actions 只验证软件构建与打包；云端 Mac 不代表笔记本角度传感器，也不进行隐私授权和实际动画验收。一次构建成功、签名结构检查或终端授权读数，都不能代替这些场景的验收。

## 已针对体验修正

- 取消桌面纵向拉伸以及每帧重复置顶。
- 增加 88° 进入 / 92° 退出的缓冲区、弱虚化淡入淡出。
- 修正未授权时手动预览无限等待、失败后保持预览标记残留。
- 固定状态区高度，减少状态文字与权限轮询频率，提供独立恢复操作。
