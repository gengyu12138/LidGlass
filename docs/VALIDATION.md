# v0.1.0 验证范围

## 发布前已验证

- Swift 类型检查、原生应用完整构建、Info.plist 格式和 ad-hoc 签名完整性。
- 应用图标与实际控制窗口布局；权限不足时禁用预览并给出入口。
- 自动效果开关关闭与重新开启。
- DMG / ZIP 的 SHA-256 校验、DMG 镜像校验、只读挂载后的应用签名、安装说明与许可证文件。
- 在 MacBook Pro M1 Pro（MacBookPro18,3）观察到实际角度读数。

## 仍待验证

- 最终发布构建在录屏授权生效后的保持/结束预览、Esc 恢复。
- 最终发布构建的真实开合盖、88°–92° 临界区与唤醒/锁屏回归。
- 其他 MacBook 型号、不同缩放设置、多显示器及完整安装/升级流程。
- Developer ID 签名与 Apple 公证。当前维护环境没有可用签名身份，也尚未加入 Apple Developer Program。

GitHub Actions 只验证软件构建与打包；云端 Mac 不代表笔记本角度传感器，也不进行隐私授权和实际动画验收。一次构建成功、签名结构检查或终端授权读数，都不能代替这些场景的验收。

## 已针对体验修正

- 取消桌面纵向拉伸以及每帧重复置顶。
- 增加 88° 进入 / 92° 退出的缓冲区、弱虚化淡入淡出。
- 修正未授权时手动预览无限等待、失败后保持预览标记残留。
- 固定状态区高度，减少状态文字与权限轮询频率，提供独立恢复操作。
